## Human-AI Copilot Framework for Product Development

A spec-driven way to work with AI coding agents, so an AI never quietly guesses its way into your product. It classifies a project along two independent axes how much definition it's worth, and what you're exposing yourself to and only asks for the rigor that classification actually requires: nothing for a private script, GDPR and accessibility checks by default for a product collecting user data in the EU.

Ships as an installable [Claude Code](https://docs.claude.com/en/docs/claude-code) plugin: 15 commands, a blind quality-gate reviewer, and compliance checklists for privacy, accessibility and security built to scale from a weekend prototype to a production product without either one carrying the other's overhead.
